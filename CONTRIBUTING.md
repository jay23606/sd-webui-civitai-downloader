# Как помочь разработке

Спасибо за желание помочь! Здесь всё просто.

## С чего начать

1. Сделайте форк репозитория и склонируйте его
2. Посмотрите открытые задачи — задачи с меткой **good first issue** лучше всего подходят для старта
3. Если хотите сделать что-то своё — сначала создайте задачу и опишите идею, чтобы не делать лишнюю работу

## Настройка окружения

Расширение работает внутри [AUTOMATIC1111 Stable Diffusion WebUI](https://github.com/AUTOMATIC1111/stable-diffusion-webui), но для большинства правок он не нужен — тесты запускаются без него:

```bash
git clone https://github.com/kushalka/sd-webui-civitai-downloader
cd sd-webui-civitai-downloader
pip install -r requirements.txt pytest
pytest tests/
```

Для проверки «вживую» склонируйте репозиторий в папку `extensions/` вашего WebUI и перезапустите его.

## Правила

- Перед PR запустите тесты: `pytest tests/` — они должны проходить
- Одно изменение — один PR, не смешивайте несвязанные правки
- Пишите простым языком: этот проект намеренно без сложных абстракций
- Сообщения об ошибках создавайте через [Issues](https://github.com/kushalka/sd-webui-civitai-downloader/issues): укажите ссылку на модель, текст ошибки и что ожидали вместо неё

## Что особенно ждём

- Вкладку в интерфейсе WebUI (сейчас всё управляется только через REST API)
- Выбор папки назначения (LoRA / checkpoints / embeddings) по типу модели
- Тесты для `extract_model_id` и обработки ошибок API
